Dessiner ensemble d'après un modèle vivant

Toutes les deux semaines, le jeudi, nous organisons une séance de dessin d'après un modèle vivant. Que vous soyez expérimenté ou débutant : chacun est le bienvenu pour travailler et croquer dans une ambiance détendue.

Après une interruption, les séances de dessin d'après modèle reprennent à partir d'octobre 2026.
